Rules to declare identifiers:
-----------------------------
1. lowercase and uppercase
2. case-sensitive
3. it allows digits (0-9)
4. it should not start with a digit
5. it allows underscore (_)
6. It should not be two or more parts
7. if an identifier start with underscore then it is private
8. no keyword or reserved words can be used as identifier

4. Variables

* variable is a named memory location
* while declaring a variable in python we need not to specify any datatype as it a dynamically typed programming language
* every value has its variable

5. Multiple assignment

* it is the process of assigning a single value to multiple variable
* it is the process of assigning multiple value to multiple variables

6. Indentation --- 4 spaces

in other programming languages

int i = 100;
if (i == 10) {
    printf("true");
} else {
    printf("false");
}

in python

i = 100
if (i == 10):
    print("true")
else:
    print("false")

working with str:
-----------------
1. str is a group of characters or sequence of characters 
2. we can create a str by using '' or "" or ''' ''' or """ """
3. str is immutable that means once we create a str that cannot be modified directly

*mutable: we can change or modify
*immutable: we cannot change or modify

working with list:
------------------
1. list is ordered collection of elements 
2. we can create list by using []
3. it allows duplicate elements 
4. it allows different datatypes elements 
5. list is mutable, we can modify directly

working with tuple:
------------------
1. list is ordered collection of elements 
2. we can create list by using ()
3. it allows duplicate elements 
4. it allows different datatypes elements 
5. tuple is immutable, we cannot modify tuple 
6. to create a tuple with single element then after the element we should provide a comma sign (,)
7. tuple is more efficient as compared to list

working with range:
-------------------
1. range is used to generate sequence of values 
2. we can create a range by using range() function 
3. by default range will start from 0
4. range is immutable we cannot modify it  

working with set:
-----------------
1. set is unordered collection of unique elements 
2. we can create a set by using {}
3. to create an empty set we use set() function 
4. it allows the different datatype elements 
5. it will not allow duplicate element 
6. set is mutable, we can modify a set 

frozen set is immutable where as set is mutable 

working with dict: 
------------------
1. dict is collection of items 
2. in dict, each item can be a pair i.e. key:value 
3. we can create a dict by using {}
4. in dict keys must be unique and keys are immutable 
5. in dict values are mutable and values need not to be unique 
6. in dict, keys and values can be of any datatype (key rule should satisfy)

Operators:
----------
1. Arithmetic

+ --- Addition
- --- Subtraction 
* --- Multiplication 
/ --- Division 
% --- Modulus
** --- Power 
// --- Floor Divide 

2. Relational 

< --- Less than 
> --- Greater than 
<= --- Less than or equal to 
>= --- Greater than or equal to 
== --- Equal to 
!= --- Not equal to

3. Assignment 

= --- Assign 
+= --- Add and assign 
-= --- Subtract and assign 
*= --- Multiply and assign 
/= --- Division and assign 
%= --- Modulus and assign 
// --- Floor division and assign 

4. Logical 

and : it returns True if both conditions are True 
or : it returns True if any one of the condition is True or both the conditions are True else False
not : it returns True if condition is False 
      it returns False if the condition is True 

5. Membership

* Membership Operators are used to check whether the element or value is present in given sequence or not 

in: returns True if the element or value is present in the given sequence else False 
not in: returns True if the element or value not present in given sequence else False 

6. Identity

* Used to check whether variables are having same identity or not 

is: returns True if the variables are having same identity else False  
is not: return True if the variables are not having same identity else False 

id(): it is a built-in function
      it is used to get the memory address of the variable 
      it will return a unique integer

7. Bitwise

* Used to peform bit by bit operations on integers for faster calculations 

1. Bitwise AND (&)
2. Bitwise OR (|)
3. Bitwise XOR (^) # --- if both bits are same then False else True 
4. Bitwise NOT (~) # --- ~n = - (n + 1)
5. Bitwise Left Shift (<<)
6. Bitwise Right Shift (<<)

Conditional Flow Statements:
----------------------------

1. Conditional Statements
    * if 
    * if else 
    * nested if 
    * elif 

2. Iterative Statements
    * for : is used to iterate elements of collection what the order they appear
    
    * nested for loop: loop which is inside another loop

        NOTE: for every single iteration of outer loop, inner loop should finish its all the iterations then only the outer loop will start with its next iteration  
        
    * while : is used to execute the number of statements as long as the condition is True.
              Once the condition becomes False then control flow will jump out of the while loop. 

3. Transfer Statements
    * break : is used to stop iteration based on the condition 
    * continue : it is used to skip the current iteration and it will continue with next iteration 
    * pass : is a keyword and used to make an empty block
